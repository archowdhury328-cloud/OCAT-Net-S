# Data statement
* Internal: Kaggle "Oral Cancer Images for Classification" (Muhammad Atef). Release/version, licence, checksums and class mapping must be recorded by `ocat audit-data` at download time (not yet done: no access in the build environment).
* Labels: image-level, Normal=0, Oral Cancer=1. No patient IDs, acquisition metadata or biopsy confirmation.
* External (pending verification of exact records, versions, licences, counts): SMART-OM (Normal vs OSCC) and the Oral Images Dataset (benign vs malignant). Never used for training, selection, calibration or normalisation.
* Images and per-image records are not redistributed by this repository.
